Biorąc pod uwagę liczbę wykorzystanych bibliotek uruchomienie aplikacji może być problematyczne.
Celem wykonanego projektu była przedewszystkim nauka nowych bibliotek oraz technologii.
Dlatego między innnymi backtest jest uruchamiany w kontenerze docker, biblioteka wykorzystana do stworzenia aplikacji to QT.

RUN: python desktop_dashboard/main_gui.py
Następnie za pomocą interfejsu GUI, użytkownik wybiera z pośród dostępnych opcji.
Możliwe scenariusze:
1) trening modelu
2) predykcja
3) backtest/symulacja portfela
4) 1+2+3 lub 2+3
5) analiza zapisanych wyników

Biorąc pod uwagę skomplikowany oraz nieczysty kod zamieszczam zrzuty ekranu w celu ułatwienia przeprowadzenia oceny.
